# 🚑 DropAid — Smart Ambulance Booking & Coordination

**The right help, closer when every minute matters.**

DropAid is a healthcare technology web application designed to simplify ambulance booking and improve emergency transportation coordination. It provides a location-aware booking experience, ambulance assignment, route visualization, trip tracking, and hospital destination support through an interactive working simulation.

Built by **Team Error Not Found** as a hackathon project, DropAid explores how technology can make ambulance coordination more accessible, organized, and transparent.

## 🌟 Key Features

- 🚨 **Quick Ambulance Booking** — An interactive emergency booking button activated by a 5-second hold.
- 📍 **Location-Aware Booking** — Supports location-based ambulance requests and pickup visualization.
- 🚑 **Ambulance Matching** — Demonstrates the assignment of available ambulances based on the implemented dispatch logic.
- 🗺️ **Map & Route Visualization** — Displays locations and ambulance routes through the application's mapping functionality.
- 📡 **Live-Style Trip Tracking** — Visualizes ambulance movement and trip progress in the simulation.
- 🏥 **Hospital Destination Support** — Includes hospital locations and destination selection in the booking workflow.
- 🚦 **Fleet Coordination Simulation** — Demonstrates ambulances distributed across different locations and changing trip statuses.
- 💻 **Responsive Interface** — Designed for a clean, accessible experience across desktop and mobile screens.

## 🎯 Problem Statement

During emergencies, finding an available ambulance and coordinating its journey can be challenging. Limited visibility into vehicle availability, location, and destination options can complicate the process.

DropAid explores a technology-driven approach to make ambulance booking and dispatch more organized through a unified digital workflow.

## 💡 Our Solution

DropAid brings together the essential stages of an ambulance booking journey:

1. The user initiates an ambulance booking.
2. The application processes the booking request.
3. An available ambulance is assigned according to the implemented dispatch logic.
4. The user can view the ambulance's route and simulated trip progress.
5. The journey and hospital destination can be visualized through the application.

The project focuses on demonstrating how location-aware interfaces and fleet coordination logic can support a more connected emergency transportation experience.
